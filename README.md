📖 Project Description

Wingo is an intelligent tourism discovery platform dedicated to Tunisia.
It allows users to explore Tunisian regions, discover the best seasons to travel, find unique local experiences, and promote local tourism.

The project combines both a web application and a desktop application to provide a complete and accessible experience for different types of users.

🚀 Project Idea

Wingo offers an interactive and intuitive way to discover Tunisia through:

An interactive map of regions
Recommendations for the best travel seasons
Highlighting local experiences
Promoting Tunisian local products
Supporting local artisans and producers
🎯 Project Objectives
Simplify travel planning in Tunisia
Highlight lesser-known Tunisian regions
Encourage local and responsible tourism
Provide a personalized travel experience
Promote Tunisian culture, traditions, and local products
🧩 Main Features
🌍 Web Application (Symfony)
Interactive map of Tunisia

Seasonal travel recommendations
